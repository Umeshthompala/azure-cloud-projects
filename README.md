# Azure Cloud Infrastructure Projects

Welcome to my Azure Cloud Infrastructure Projects repository.

This repository contains two individual hands-on projects implemented using Microsoft Azure. These projects helped me gain practical knowledge of cloud networking, load balancing, multi-tier architecture, and network security.

## Project 1: Two-Tier Architecture Using Azure Load Balancer

**Technologies:** Microsoft Azure, Ubuntu, Nginx, Apache Tomcat, Virtual Network, Load Balancer, Network Security Groups.

- Created separate web and application tiers using Azure Virtual Machines.
- Configured Azure Virtual Networks and subnets.
- Implemented Public and Internal Load Balancers.
- Configured backend pools, health probes, and load-balancing rules.
- Used Nginx as a reverse proxy to communicate with the application tier.
- Tested connectivity and troubleshot network communication.

## Project 2: Three-Tier Architecture Using Azure Network Security Groups

**Technologies:** Microsoft Azure, Ubuntu, Nginx, Apache Tomcat, MySQL, Virtual Network, Network Security Groups.

- Implemented separate web, application, and database tiers.
- Deployed three Ubuntu Virtual Machines across separate subnets.
- Configured NSG rules to control communication between tiers.
- Restricted direct access from the web tier to the database tier.
- Tested connectivity using SSH, ping, Netcat, curl, and MySQL.

## Key Learnings

- Azure Virtual Machines and Virtual Networks
- Subnetting and network security
- Azure Load Balancer configuration
- Network Security Group rules
- Multi-tier cloud architecture
- Linux server administration and troubleshooting
